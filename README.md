# Maitre API Reference

This repository contains the API reference for **[Maitre API](https://github.com/ffvasconcelos/maitre-api)**, organized as a [Bruno](https://www.usebruno.com/) collection.

The collection provides example requests to explore and test the API endpoints.

## Getting Started

### Prerequisites

- [Bruno](https://www.usebruno.com/) installed.
- [Maitre API](https://github.com/ffvasconcelos/maitre-api) running locally.

### Usage

1. Clone this repository.
2. Open Bruno and select **Open Collection**.
3. Select the cloned repository folder.
4. Ensure the Maitre API is running at `http://127.0.0.1:8000`.
5. Select a request and send it to interact with the API.

> **Note:** Maitre API is a work in progress. Available endpoints and request definitions may change as development progresses.
